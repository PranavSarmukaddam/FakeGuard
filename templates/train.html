This will run src/train_model.py which performs the following steps:

  1. Load dataset from data/raw/Fake.csv and True.csv (or built-in sample data if not found)
  2. Preprocess all articles: cleaning, tokenization, stop-word removal, lemmatization
  3. Build TF-IDF feature vectors with bigram support
  4. Split data into 80% training and 20% test sets
  5. Train Logistic Regression, Naive Bayes and Linear SVM classifiers
  6. Evaluate all models and select best by F1-score
  7. Save vectorizer, model, corpus matrix and evaluation JSON to models/
For best results: Download Fake.csv and True.csv from Kaggle and place them in data/raw/ before training. Without them, the built-in sample dataset (32 articles) will be used automatically. You can also run python src/download_dataset.py to attempt auto-download.
